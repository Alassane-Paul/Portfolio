# Portfolio — ALASSANE Paul

Portfolio personnel d'ALASSANE Paul, développeur web et mobile basé au Togo. Le site présente son parcours, ses compétences, ses services, ses projets et ses coordonnées.

## Aperçu

Le portfolio comprend :

- une page d'accueil et une présentation du profil ;
- les compétences et services proposés ;
- une sélection de projets réalisés ;
- les étapes de travail ;
- les coordonnées et un formulaire de contact ;
- une mise en page adaptée aux mobiles et aux ordinateurs.

## Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts (Poppins)

Le site est statique et ne nécessite ni dépendances ni étape de compilation.

## Lancer le site en local

1. Clonez le dépôt :

   ```bash
   git clone https://github.com/Alassane-Paul/Portfolio.git
   ```

2. Ouvrez le dossier du projet.
3. Ouvrez `index.html` dans un navigateur, ou utilisez l'extension **Live Server** de Visual Studio Code.

## Structure du projet

```text
Portfolio/
├── images/          # Images et favicon
├── Script/
│   └── script.js    # Menu mobile et interaction du formulaire
├── Style/
│   ├── carte.css    # Styles de la carte de profil
│   └── home.css     # Styles principaux
└── index.html       # Page du portfolio
```

## Formulaire de contact

Le formulaire actuel fonctionne uniquement côté navigateur : à l'envoi, il affiche un message de confirmation puis réinitialise les champs. Il n'envoie pas encore les messages par e-mail et ne les stocke pas. Un service ou un backend devra être connecté pour recevoir les demandes.
